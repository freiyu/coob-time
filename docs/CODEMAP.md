## 4. Public interfaces (what other code may call; names and one-line purpose only)
Runtime helpers come from `src/lib/puzzles.ts`, `src/lib/statistics.ts`, `src/lib/timer/`, `src/lib/scrambles/`, `src/lib/storage/idb.ts` and `src/lib/backup/`; UI components are default-exported internals.
- Types: `Penalty` ("none" | "plus2" | "dnf"), `InspectionMode` ("off" | "15s" | "wca"), `TimerPenalty` (same as Penalty), `TimerStop` (`{rawTimeMs, penalty}`), `PuzzleId` (10-id string union), `Puzzle`, `SolveRecord`, `SolveLike`; `SettingsRecord.inspectionMode` (default "off"), `soundEnabled` (default false), `autoNextScramble` (default true), `hideTimer` (boolean, default false; readers use `settings?.hideTimer === true` — undefined → off, no DB migration)
- `PUZZLES` — the 10 supported puzzle ids/labels
- `puzzleLabel(puzzleId)` — id → display label
- `effectiveMs(solve)` — time in ms after +2/DNF penalty, null if DNF
- `formatMs(ms)` — "12.34" or "1:05.12" rendering
- `bestSingle(solves)` — fastest non-DNF ms, null if none
- `mean(solves)` — arithmetic mean of non-DNF ms
- `aoN(solves, n)` — WCA-style average of the last n (drop floor(n/5) each end; DNF in window → null)
- `bestAoN(solves, n)` — best aoN over all windows of size n
- `bestAoNEnd(solves, n)` — index after the first best window (earliest wins ties); null if none/insufficient; `bestAoN` now derives from it
- `parseMs(input)` — user-typed time string → ms; null if invalid (colon parts must be <60, rejects empty/zero/non-numeric/over-24h)
- `createTimerEngine(options)` — `performance.now()` engine (start/stop/arm/release/cancel/elapsedMs/subscribe; holdToReady opt-in, HOLD_MS=300, WCA_PLUS2_MS/WCA_DNF_MS; inspection: setInspection/startInspection/inspectionElapsedMs; stop returns TimerStop|null)
- `useTimer(options)` — React hook: engine + phase state + Space/N/D/Escape handling (skips typing targets, open menus, open dialogs — including the Space keyup `release()` so a dialog opened mid-hold can't start a solve); returns `{engine, phase, toggle, press, release}` where `press`/`release` are the extracted Space-keydown/keyup body shared with the timer card's touch gesture; takes `inspectionMode` (synced to engine) and `onSolve(rawTimeMs, penalty)`; first Space from idle/stopped enters inspection when the mode is on, gated by `canStart()` (scramble ready); Space keydown calls `preventDefault()` BEFORE the `event.repeat` guard (held Space no longer scrolls); other-key guards unchanged
- `isTypingTarget(target)` / `isInsideMenu(target)` / `isDialogOpen(root?)` — keyboard guard predicates (`isDialogOpen` = document has a `[role="dialog"]`, so timer shortcuts act on the dialog instead)
- `cubingScrambleProvider(puzzleId)` — async ScrambleProvider; cubing.js `randomScrambleForEvent` main-thread, returns ScrambleResult
- `EVENT_IDS` — PuzzleId → WCA event id (shared by adapter and scramble-view)
- Storage (src/lib/storage/idb.ts): `cubetimeDb`, `listSessions`/`listSolves`/`putSession`/`putSolve`/`deleteSolve`/`deleteSession` (session + its solves in one tx), `getSettings`/`putSettings`, `putImported(sessions, solves, settings, mode)` (replace clears in the same tx), `clearAll`, `DEFAULT_SETTINGS`, `StorageError`, `DB_NAME`/`DB_VERSION`
- Backup (src/lib/backup/): `parseBackup` (zod), `buildBackup`, `backupToCsv`, `downloadText`, `planImport`, types `ImportMode`/`ImportPlan`
- UI props: TimerCard takes `holdMode` + `saveState` + `ao5Dnf` + `inspectionMode` + `hideTimer` + `onPress()` + `onRelease()` (touch/pen gestures; wired to `timer.press`/`timer.release`) + `onSetPenalty(penalty)`; DataPanel takes `sessions, solves, settings, storageOk, storageError, onSettingsSaved, onLocalDataChanged`; SolveHistory takes `onDelete: (id) => void` + `onSetPenalty: (id, penalty) => void` + `onAddManual: (rawTimeMs) => void` + `onSetNotes: (id, notes) => void`; TopBar takes `onNewSession`/`onRenameSession(name)`/`onDeleteSession`/`onOpenDataPanel`; Dialog takes `title, onClose, wide?`. TimerCard no longer takes `onToggle` (start/stop = Space or touch/pen on the card, never a button).
- Exports: `BUTTON_BASE`/`BUTTON_SECONDARY`/`BUTTON_PRIMARY`/`BUTTON_DESTRUCTIVE` — named class-string exports from src/components/data-panel.tsx (used by data-panel, solve-history, top-bar)

## 8. Conventions and recipes
- Add a component: one file in src/components, default export, `"use client"` if it uses state/hooks; import via `@/components/...`; Tailwind classes only, colors from tokens (no raw hex); body/helper text never below `text-sm` (14px floor, DESIGN.md — `text-xs` removed from solve-history/statistics/scramble-panel in Phase 3).
- Add a puzzle or scramble type (and how it is verified): extend `PUZZLES` in src/lib/puzzles.ts + `EVENT_IDS` in src/lib/scrambles/events.ts + a case in adapter.test.ts; real generation is cubing.js in src/lib/scrambles/adapter.ts and must be marked verified in Section 5 by a test or phase report.
- Add a statistic (and its test): helper in src/lib/statistics.ts + render in src/components/statistics.tsx; colocated unit test as `*.test.ts` next to the module, run via `npm run test` (vitest, config vitest.config.mts).
- Add a timer keyboard shortcut: add a case in src/lib/timer/use-timer.ts guarded by `isTypingTarget`/`isInsideMenu`/`isDialogOpen`, plus a test in keyboard.test.ts or use-timer coverage.
- Add a storage migration: bump `DB_VERSION` in src/lib/storage/idb.ts and add a case in the openDB upgrade block. Precedent v1→v2 (settings `inspectionEnabled` boolean → `inspectionMode`): read/write the record via the upgrade `tx.objectStore("settings")` versionchange transaction — DB-level `db.get`/`db.put` start a new transaction, which throws during an upgrade.
- Client vs server components: layout.tsx/page.tsx are server components; all interactive UI hangs off the `"use client"` root src/components/timer-app.tsx. Browser-only APIs (localStorage, matchMedia) stay behind that root.
- Heavy client lib (SSR-safe): `await import(...)` inside useEffect with a cancelled flag + cleanup — the pattern in src/components/scramble-view.tsx.
- Async result into state (satisfies react-hooks/set-state-in-effect): resolve the promise with `.then(...)`, guard staleness with a seq counter, and apply via `useCallback` — pattern in timer-app.tsx `generate`/`applyScrambleResult`.
- Derived stats under the timer: compute in timer-app from src/lib/statistics.ts helpers (e.g. `ao5 = aoN(solves, 5)`) and pass as a prop to a presentational card (pattern in timer-card.tsx).
